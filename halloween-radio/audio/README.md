# Halloween Radio Audio

Place the Brew & Brews Halloween radio MP3 files in this folder.

Current library target: **34 songs/music pieces**.

Recommended naming format:

`NN-lowercase-kebab-title.mp3`

Keep original high-quality masters outside the web repo if desired; this folder should contain the web-playback versions used by the radio.

The current interface expects `ironclad.mp3` as its initial 103.1 B&B Radio track.
